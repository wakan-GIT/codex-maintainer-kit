# Maintainer Readiness Checklist

Use this before inviting AI coding agents into an open-source repository.

- [ ] README explains what the project does and how to run it
- [ ] LICENSE is present
- [ ] CONTRIBUTING explains setup, tests, and review expectations
- [ ] AGENTS.md or equivalent guidance exists
- [ ] test command is documented and works locally
- [ ] CI runs tests on pull requests
- [ ] CHANGELOG or release notes exist
- [ ] SECURITY explains vulnerability reporting
- [ ] sample files do not contain real credentials
- [ ] maintainers know which actions require human approval
