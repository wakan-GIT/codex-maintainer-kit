# Agent Instructions

Use these rules when working in this repository.

- Run `npm test` after source changes.
- Keep changes small and focused on the requested issue.
- Do not add secrets, tokens, private URLs, customer data, or production logs.
- Update README or CHANGELOG when behavior changes.
- Prefer dependency-free solutions unless a dependency is clearly justified.
- Ask a maintainer before publishing packages, creating releases, changing visibility, or performing external writes.
